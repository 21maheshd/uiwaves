Key Features of the UI Waves runtime:

  • Framework Agnostic: Plain JavaScript runtime that integrates easily with React, Angular, Vue, VanillaJS, and existing web applications.
  • API-Driven Data Experience: Connect an API and quickly create an interactive dynamic data workspace without rebuilding common data management features. Supports REST API to persist user state so that view can be restored across sessions.
  • Zero Boilerplate: Reduce repetitive frontend development for tables, filtering, sorting, grouping, layouts shifts, and data interactions.
  • Interactive Data Workspace: Work with the same data through multiple experiences such as Grid, Cards, Details, and Compare views.
  • Context-Aware Assistant: Understands the current table, selected records, columns, filters, sorting, and active view before executing actions.
  • Natural-Language Commands: Perform data and UI operations using simple commands such as "hide column", "group by status", "Highlight ICICI rows with yellow color", "Rename Status to Updated Status", "Add $ before the Amount"
  • Smart Command Engine: Convert user commands into validated, deterministic runtime actions.
  • Intent Validation: Validate commands and available operations before execution to prevent unintended changes.
  • Quick Column Actions: Easily hide, show, group, freeze, and manage columns.
  • Data Operations: Support filtering, sorting, grouping, pagination, searching, highlighting with preferred colors, and data transformations.
  • Dynamic Views: Switch between Grid, Cards, Details, and Compare views without rebuilding the underlying data experience.
  • Schema-Driven UI: Automatically understand API data types and generate appropriate presentation and interaction controls.
  • CRUD Ready: Support configurable create, edit, delete, and duplicate operations using customer-provided APIs or callbacks.
  • Server-Side Data Support: Designed for server-side pagination, sorting, filtering, grouping, and large datasets in paid plans.
  • Undo & Redo: Quickly reverse or restore workspace and presentation changes.
  • Command History: Track recent commands and repeat commonly used data operations.
  • Draggable Assistant: Flexible assistant interface that can be positioned according to the application's layout.
  • Prompt Suggestions: Provide ready-to-use prompts and quick actions to help users discover available capabilities.
  • Visual Customization: Dynamically adjust density, formatting, highlighting, themes, and presentation based on user actions.
  • Extensible Event Bus: Allow applications to listen to runtime events and extend or customize behavior.
  • DOM Runtime Layer: Centralized DOM and presentation management for consistent and predictable UI transformations.
  • Lightweight Integration: Designed to be added to an existing application with minimal configuration and without replacing the application's existing architecture.
  • Multiple Build Formats:JS, ESM, UMD, and IIFE builds to support different application and deployment environments.
